  <h1>ColabFold-Rosetta Pipeline</h1>

  <p>

    This pipeline takes a protein FASTA sequence, generates structure predictions with ColabFold,

    clusters the models, selects representative conformations, runs Rosetta neighbor-count analysis,

    and ranks residues/reagents for covalent labeling experiments.

  </p>


  <h2>Repository contents</h2>

  <ul>

    <li><code>Dockerfile</code></li>

    <li><code>run_pipeline.sh</code></li>

    <li><code>requirements.txt</code></li>

    <li><code>pipeline_steps/</code></li>

  </ul>


  <h2>Large downloadable files</h2>

  <p>

    The Docker image archives are provided under the GitHub Releases section:

  </p>

  <ul>

    <li><code>cl_pipeline_docker_build_min.tgz</code></li>

    <li><code>colabfold-rosetta-pipeline.tar.gz</code></li>

  </ul>


  <h2>Example run</h2>

  <pre><code>gunzip -c colabfold-rosetta-pipeline.tar.gz | docker load


docker run --rm \

  -v /path/to/input:/data/input \

  -v /path/to/output:/data/output \

  -v /path/to/rosetta/bin:/rosetta/bin:ro \

  -e ROSETTA_BIN=/rosetta/bin/per_residue_solvent_exposure \

  colabfold-rosetta-pipeline:latest \

  bash /opt/pipeline/run_pipeline.sh YOUR_UNIPROT /data/input/input.fasta /data/output

</code></pre>
